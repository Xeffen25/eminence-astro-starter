# SEO Ready with eminence-astro-suite

SEO defaults are integrated to reduce missed metadata while developing pages.

## Workspace Skill Note

The `eminence-astro-suite` skill is installed in this workspace. When creating or updating Astro pages and metadata, use the installed skill guidance as the default source of truth.

## Included Benefits

- Structured defaults for title/description.
- Build-time reminders for missing SEO metadata.
- Consistent head configuration through layouts.

## Recommended Workflow

1. Follow the installed `eminence-astro-suite` skill guidance for metadata and SEO conventions.
2. Set page-specific title and description for each route.
3. Run `pnpm build` regularly.
4. Resolve metadata warnings before release.

## Checklist

- Confirm page metadata aligns with the installed `eminence-astro-suite` skill.
- Unique title per page.
- Useful description per page.
- Correct locale/language handling.
